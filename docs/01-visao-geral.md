# BarberTime

Buscamos desenvolver um sistema web de gerenciamento de agendamentos para barbearias, permitindo que clientes encontrem estabelecimentos consultem horários disponíveis e realizem agendamentos. 

Os responsáveis (que podem ser citados como "administradores" na documentação) por barbearias poderão administrar seus estabelecimentos, profissionais, horários e atendimentos.
